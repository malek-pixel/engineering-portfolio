# Future Projects (Planned)

The following projects are **planned**, building directly on the F1 Data Project dataset and pipeline. None of these are started yet - they're listed here to show direction and intent.

## [Planned] Interactive F1 Dashboard

A web-based dashboard (likely Plotly Dash or Streamlit) built on top of the existing `results.csv` dataset, letting users filter by season, constructor, or driver and explore win-rate trends interactively instead of through static charts.

## [Planned] Race Strategy Simulator

A simplified simulator modeling basic race-strategy decisions (pit stop timing, tire choice) against historical race data, to explore how strategic choices affect outcomes.

## [Planned] Telemetry Analysis Toolkit

A toolkit for working with car telemetry data (speed, throttle, braking) once a suitable public data source is identified - extending the project from results-level analysis to car-performance-level analysis.

## [Planned] Lap Time Prediction

A basic predictive model estimating lap times from race conditions and historical patterns, as an introduction to applied statistics and simple machine learning.

## [Planned] Tire Degradation Modeling

A model exploring how tire performance degrades over a stint, using available public data, to connect data analysis with vehicle performance concepts.

## [Planned] Vehicle Performance Analytics

Broader analysis connecting race results to vehicle and team performance trends - a bridge between the data-analysis work here and hands-on vehicle-performance engineering.

Status legend: [Planned] = not yet started.
